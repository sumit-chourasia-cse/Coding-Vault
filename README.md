# CodingVault

A beginner-friendly website for exploring programming languages and finding a place to start.

## What it includes
- Introduction pages for Python, Java, C, C++, C#, JavaScript and TypeScript
- Learning pages with code examples
- A short quiz to help learners choose a starting language

## Technologies and development
HTML, CSS and JavaScript; built through an AI-assisted vibe-coding workflow.

## My contribution
I created the website using a vibe-coding workflow, with AI assistance in generating the code.
